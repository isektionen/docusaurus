# IT-Responsible

The IT-Responsible is an elected one-person position responsible for the operation and maintenance of the chapter's websites and other IT systems, as well as for who has access to them. In consultation with the board, the IT-Responsible also works strategically on developing the chapter's IT systems. To help with this, the IT-Responsible recruits the IT group [I-Tech](../projects/i-tech.md), which supports the operational IT work.

You can turn to the IT-Responsible if you have questions about the chapter's website or IT systems, need help with access, or have an idea for something that could be improved.
